# Android workspace adaptation

Mode: Operate. Scope: src/mobile. This extends the desktop's approved structural-index direction into Android's existing native wrapper, rather than choosing a new unrelated visual world.

## Direction contract

THESIS: A clear mobile scenario library and structural index, with destructive actions contained and the manuscript stable while reading.
OWN-WORLD: Nine semantic color families, including shared 黒金, 桜 and 深海. Tonal header and mode controls, readable paper, uniform 48px primary touch targets, 12px document surfaces, neutral delete icons and a red swipe reveal only during movement.
STORY: Open or create a scenario, search local drafts, confirm draft deletion without touching original files, search the outline with ancestry, read or edit the manuscript, and inspect the read-only flow.
FIRST VIEWPORT: Phone top bar with current screen and settings, stacked open/create actions, a draft count and search, full-width document rows with separate delete controls. In a document, outline, grouped body/flow modes and notes remain independent; formatting stays above the keyboard.
FORM: Adaptation of the existing desktop bound-manuscript direction; no replacement world. Native Android captures, phone and expanded viewport, light and dark, font-scale and keyboard checks.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
