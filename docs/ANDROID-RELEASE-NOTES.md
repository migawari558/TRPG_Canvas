# Android v0.1.0

Android向けの初回正式配布です。APKをダウンロードして開き、Androidの案内に従ってインストールしてください。

- スマートフォン向けのライブMarkdown本文編集、階層を折り畳める目次、執筆メモ。
- Google Driveなどの文書プロバイダーから、PC版と同じ `.trpg.json` を開いて自動保存できます。
- 外部の更新はシナリオを開き直した時に読み込みます。保存時に競合があれば元ファイルを上書きせず、端末に競合コピーを保護して編集を続けます。
- フローチャートは閲覧専用です。
- 表示テーマ、本文サイズ、端末下書きのスワイプ削除、アプリ内の更新確認に対応します。

## 試作版からの移行

GitHub Actionsから入れたデバッグ試作版とは署名が違います。必要な下書きを必ずDriveなどのファイルに保存してから試作版をアンインストールし、この正式版をインストールしてください。アンインストールすると端末内の下書きと設定は消えます。

この正式版以降は固定署名で配布します。次回からは設定の「更新を確認」で配布ページを開き、APKを上書きインストールできます。

Driveのクラウド反映には時間差があります。初回の保存先選択は必要です。アプリ停止中の常駐同期は行いません。競合コピーをDriveへ保存する際は、そのコピーの初回保存先を選択してください。
