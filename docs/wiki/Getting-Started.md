# 使い始める

## アプリを入れる

1. [Releases](https://github.com/migawari558/TRPG_Canvas/releases)を開きます。
2. PC版は最新の `v…`、Android版は最新の `android-v…` を開きます。
3. **Assets** から下表のファイルを取得します。`Source code` はアプリ本体ではありません。

| 端末 | ファイル |
| --- | --- |
| Windows | `…windows-x64-setup.exe`（通常はこちら） |
| Windows・インストール不要 | `…windows-x64-portable.exe` |
| Apple Silicon Mac・Mシリーズ | `…mac-arm64.dmg` |
| Intel Mac | `…mac-x64.dmg` |
| Android | `TRPG-Canvas-android-v….apk` |

Windowsはexeを起動します。Macはdmgを開いてアプリをApplicationsへドラッグします。AndroidはAPKを開き、必要に応じて取得に使ったブラウザ／ファイルアプリからのインストールを許可します。

Mac版はAppleによる署名・公証を行っていません。起動時の開発元警告については、配布元を確認したうえで[Appleの案内](https://support.apple.com/ja-jp/102445)を参照してください。

## 新しいシナリオを書く

1. 一覧から新規作成し、タイトル・システム名・説明を入力します。
2. [フロー](Flowchart.md)から構想を組み立てるか、[本文](Writing.md)を書き始めます。
3. 編集内容は自動保存されます。保存状態を確認してください。PCでは `Ctrl+S`（Macは `Command+S`）でも保存できます。
4. Androidの新規シナリオは、保存操作で初回のファイル保存先を選びます。それまでは端末内の下書きです。

システム名はシナリオ情報で変更できます。書き出したタイトル部分にも反映されます。

## 更新する

PCは「保存・同期」→「更新を確認」、Androidは設定の「更新を確認」を使います。案内された配布ファイルを開いて更新してください。正式Android版同士はAPKを上書きインストールできます。

アプリ本体とシナリオファイルは別です。更新時に保存フォルダを消す必要はありません。Androidをアンインストールすると端末内の下書きは消えるので、必要な編集は先にファイルへ保存してください。

旧デバッグAPKから正式版への移行は[Androidガイド](Android.md)を参照してください。
