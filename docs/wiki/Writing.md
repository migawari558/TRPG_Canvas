# 本文を書く

本文はMarkdown記法がその場で見た目に反映されるエディタです。記法を覚えなくても修飾ツールバーから操作できます。ボタンにマウスを重ねると操作や記法を確認できます。

PCでは原稿の上に「本文」「フロー」の切り替えと修飾ツールバーが並びます。「執筆メモ」は右側のボタンから開けます。

## よく使う記法

行頭の記法は、記号のあとにスペースを入力して変換します。

| 表現 | 入力例 |
| --- | --- |
| 章（H1より上・中央揃え） | `#! 第一章` |
| 見出し | `# 大見出し`、`## シーン`、`### 小見出し`（H6まで） |
| 太字・斜体・打ち消し | `**太字**`、`*斜体*`、`~~打ち消し~~` |
| 下線 | ツールバー、またはMarkdownで `<u>下線</u>` |
| 箇条書き・番号付き | `- 項目`、`1. 項目` |
| チェックリスト | `[] 項目`、`[x] 完了`（`- [ ]` も対応） |
| 引用 | `> 読み上げる文章` |
| GMメモ | `!!!` のあとにスペース |
| セリフ | `::コレット` のあとにスペース |

通常のEnterは段落、Shift+Enterは段落内改行です。本文では両者の行間を揃えています。表・脚注・任意HTMLなど、Markdownのすべての拡張には対応していません。

## 目次で移動・整理する

章と見出しが目次になります。項目を選ぶと本文の該当箇所へ移動できます。子見出しは折りたため、上部の「すべて閉じる」「すべて開く」でまとめて切り替えられます。

PCでは目次の上下ボタンで、見出しと配下の本文・小見出しをまとめて並べ替えます。同じ親・同じレベルの見出し間で移動し、元に戻す操作も使えます。

目次の検索欄に見出し名を入力すると、該当する見出しとその親の章・見出しが表示されます。検索をクリアすると、検索前の開閉状態に戻ります。PCでは目次を閉じても左のアプリアイコンは表示され、そこからシナリオ一覧へ戻れます。

## GMメモと執筆メモの違い

**GMメモ**は本文中の網掛け枠です。ツールバーまたは `!!!` とスペースで開始します。`Ctrl+Enter` で枠の外に通常の段落を作れます。Markdown保存形式は次のとおりです。

```markdown
:::gm
判定に成功したら追加情報を伝える。
:::
```

GMメモは配布用のHTML・PDF・Wordにも含まれます。自動で非公開にはなりません。

**執筆メモ**は本文と別の構想メモです。本文とフローのどちらでも参照でき、ライブMarkdownで編集できます。PCではパネルの幅も変更できます。配布用の書き出しには含まれません。

## セリフを書く

行頭で `::話者名` のあとにスペース、または `Ctrl+Shift+D`（Macは `Command+Shift+D`）で追加します。話者名はその場で入力できます。NPC登録は不要です。

```markdown
:::dialogue コレット
ようこそ。こちらでお待ちしていました。
:::
```

話者名は太字になり、名前の長さに応じて本文との間隔が変わります。PDFで長いセリフがページ・段をまたぐ場合は続きにも話者名を表示します。

## 画像・検索

画像はツールバー、貼り付け、ファイルのドロップで挿入します。画像を選ぶと25%・50%・75%・100%から幅を変更できます。PNG・JPEG・GIF・WebPに対応し、画像はシナリオ内に埋め込みます。画像やBase64は文字数に数えません。外部URL・相対パスの画像は画像ファイルとして挿入してください。

検索・置換パネルでは「前へ」「次へ」で該当箇所に移動し、置換できます。フローのカード検索は[フローガイド](Flowchart.md)をご覧ください。
