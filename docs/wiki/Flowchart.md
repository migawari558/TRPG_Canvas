# フローを作る（PC版）

フローは左から右へシナリオの進行を整理する場所です。Androidでは閲覧・本文への移動に使い、カードの編集はPCで行います。

## シーンから本文を書く

1. 「シーン」でカードを追加し、名前を入力します。
2. 接続点どうしをドラッグして、進行の矢印でつなぎます。
3. シーンを選び「本文を書く」で、対応する見出しと執筆欄を作ります。
4. 本文があるシーンは「本文を開く」で戻れます。本文は重複作成されません。

カードはグリッドに沿って配置でき、「左→右に整列」で整理できます。接続点から空白へ線を引いて、新しいシーンを作成することもできます。矢印をダブルクリックすると分岐条件を編集できます。

カードや詳細欄から名前・シーンメモ・タグを編集できます。シーンメモとタグは構想用で、本文には自動挿入されません。

## グループにまとめる

「グループ」で枠を追加し、シーンを枠内へドラッグすると所属させられます。複数選択後の「まとめて移動」でも同じグループへ移せます。入れ子も可能です。カード全体を外へ出して離すと所属を解除します。

グループは折りたためます。枠の削除だけでは中のシーンや本文は消えません。所属を変えても本文の順序や見出し階層は変わりません。

## 情報カードを使う

シーンを選んで「情報を追加」すると、そのシーンで提示する情報を整理できます。情報名・内容・開示条件を記録でき、1つのシーンに複数の情報を紐づけられます。破線は情報との対応、矢印はシーンの進行です。情報カードの内容は本文へ自動挿入されません。

## 既存の本文から作る

「既存の本文から」→「H1をグループ・H2をシーンに」で、章を上位グループ、H1をグループ、H2をシーンにできます。H3以下からはカードを作りません。

既存のカードは詳細欄の「対応する目次」から見出しへ紐づけます。シーン名と見出し名は別々に変更できます。見出しを削除した場合はリンク先を選び直してください。

## 複数選択・検索・ショートカット

背景のドラッグで範囲選択、Ctrl＋クリック（MacはCommand）で複数選択します。Deleteや「選択を削除」でカードを削除しても、対応する本文は削除されません。右ドラッグで画面を移動します。

| キー | 操作（フローにフォーカスがあるとき） |
| --- | --- |
| N / G | シーン／グループ追加 |
| I | 情報追加 |
| Shift+N | 次のシーンを追加して接続 |
| C | 接続操作 |
| P | 名前・メモ・タグを検索 |
| F2 | 選択項目を編集 |
| F | 全体表示 |

入力欄で文字を入力しているときは、文字入力を優先します。
