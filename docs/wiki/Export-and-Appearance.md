# 表示と書き出し（PC版）

## 執筆画面を調整する

表示設定でテーマ・文字サイズ・インストール済みフォントを選べます。「要素ごとに設定」を有効にすると、本文・章・H1〜H6・セリフの話者名へ別々のフォントを指定できます。別の端末にないフォントは標準フォントへ切り替わります。

フォレスト、Tahoeライト／ダーク、羊皮紙、ミッドナイト、モノクロなどのテーマを利用できます。「このテーマをもとに作る」から背景・アクセント・見出し色を調整し、自作テーマとして保存できます。補助色は自動で組み合わせます。表示設定と自作テーマは端末ごとの設定です。

「黒金」「桜」「深海」はPCとAndroidの両方で選べます。

## 形式を選ぶ

「書き出す」から形式を選び、テーマ・文字サイズ・フォントを指定します。「画面と同じ設定」で執筆中の設定をコピーできます。

| 形式 | 用途・特徴 |
| --- | --- |
| HTML | ブラウザで読む。開閉式の目次、本文へのリンク、引用・コードのコピーボタンを収録 |
| PDF | 印刷・配布。用紙サイズ・段組みを指定し、実際に生成したページをプレビュー |
| Word（.docx） | Wordで編集する。用紙サイズ・段組みを指定可能。プレビューは参考表示 |
| Markdown（.md） | 本文をテキストで持ち出す。フロー・執筆メモは含みません |

HTMLは外部サーバーやCDNなしで表示できます。コピーボタンがブラウザの制限で使えない場合は手動でコピーしてください。書き出し設定画面のコピーボタンは表示見本です。

## PDF・Wordの設定

- 用紙：A4・A5・B5（JIS）・レター
- 本文：1段／2段組み
- 文字サイズ：7〜28px
- 本文・章・見出し・話者名のフォント、テーマ、フローの掲載

タイトルとフローは全幅、2段組みの本文は左段→右段→次ページの順です。Wordの最終的な改ページはWord側で決まり、目次もWordで開いた際に更新されます。

PDFでは最初を除く章・H1で改段します。連続した章・H1は手前で余分な改段が入らないようにします。段頭の空行は省き、途中の空行は保持します。GMメモなどは可能なら同じ段に収め、一段より長いものは分割します。長いセリフの続きにも話者名を表示します。

## 配布前に確認すること

GMメモは配布ファイルにも入ります。執筆メモとシーンメモは本文の書き出しには含まれません。タイトル上部にはシナリオに設定したシステム名を表示します。プレビューで見出し、画像、段組みを確認してから保存してください。
