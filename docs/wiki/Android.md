# Androidの操作とよくある質問

## 画面の使い方

Androidのホーム画面やアプリ一覧では、黒金のダイスがTRPG Canvasの目印です。

- 上部左のボタン：目次。見出しへの移動、検索、階層の開閉ができます。
- 上部右のボタン：執筆メモ。本文と別にMarkdownでメモを書けます。
- 上部中央：本文／フローの切り替え。フローは閲覧専用です。
- キーボード直上：「書式」「挿入」などの修飾操作。
- ホームの設定：文字サイズ・配色、更新確認など。

本文の初期文字サイズは14pxです。下へスクロールすると上部の操作部分を収納し、目次・メモのボタンは残ります。フローは全体表示・拡大縮小ができ、図の下でシーンと情報の一覧も確認できます。

## PCのシナリオを編集するには？

「ファイルを開く」で、PCが保存しているものと同じ `.trpg.json` を選びます。Androidのファイル選択画面からDriveを使います。[保存と同期の手順](Saving-and-Sync.md)を参照してください。

## 保存したのにPCへ反映されない

Driveのアップロード・PCへのダウンロードには時間差があります。Drive側の同期状態を確認して待ち、PCで一覧を再読込してシナリオを開き直してください。Androidで開いているファイルとPCの保存先が同じかも確認してください。

## PCで変えた本文がスマホへ反映されない

Driveの同期後に、スマホで一覧へ戻ってシナリオを開き直してください。編集中の本文を自動で差し替えない仕様です。

## 下書きを消したい

ホームの検索欄で下書きを探せます。下書きのゴミ箱ボタンを押すか、左へスワイプして確認画面を開き、削除します。消えるのは端末内の下書きです。元のDriveファイルは残ります。

## 「読み込めないファイル」と出る

拡張子だけを変えたファイルではなく、TRPG Canvasが保存した `.trpg.json` を選んでください。PC互換のファイル名は `<ID>.trpg.json` です。旧Android試作版のタイトル名ファイルは、現行版で保存するとID名へ変更します。同期の途中なら完了を待って再度開いてください。問題が続く場合は元ファイルを残し、バックアップを取って確認してください。

## アプリを入れ直してもよい？

アンインストールすると下書きと設定が消えます。先に必要なものをDriveなどのファイルへ保存してください。正式版同士の更新は、同じ署名のAPKを上書きインストールします。

GitHub Actionsの旧デバッグ試作版は正式版と署名が違います。必要な下書きを保存してから試作版をアンインストールし、正式版のAPKを入れてください。

## ブラウザでも使える？

現在の配布はPCアプリとAndroidアプリです。`npm run dev:mobile` は開発者用の画面確認で、ブラウザでのDrive保存を提供するものではありません。
