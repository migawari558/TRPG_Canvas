# TRPG Canvas 操作ガイド

初めて使う方は「使い始める」からお読みください。PC版はシナリオ全体の制作、Android版は外出先での本文・執筆メモの編集に使えます。

| ガイド | 内容 |
| --- | --- |
| [使い始める](Getting-Started.md) | ダウンロード、インストール、新規作成、更新 |
| [本文を書く](Writing.md) | Markdown、目次、GMメモ、セリフ、画像、検索 |
| [フローを作る](Flowchart.md) | シーン、本文との対応、グループ、情報カード |
| [保存と同期](Saving-and-Sync.md) | 保存先、Drive、競合、削除、旧版からの移行 |
| [表示と書き出し](Export-and-Appearance.md) | 配色、フォント、HTML・PDF・Word |
| [Androidとよくある質問](Android.md) | スマホの操作、下書き、同期トラブル |

更新内容は[リリース一覧](https://github.com/migawari558/TRPG_Canvas/releases)をご覧ください。PC版のタグは `v…`、Android版は `android-v…` です。

このガイドの原稿はリポジトリの `docs/wiki/` で管理し、リリース公開時にWikiへ反映します。
