# TRPG Canvas

TRPGシナリオを、フローチャートから組み立てて本文へつなげる執筆ツールです。Markdownベースのライブエディタ、階層目次、GMメモ、セリフ、画像、PDF・HTML・Word書き出しを備えています。

React / Tiptap / React Flow / Electronで構築しています。

## 使い始める

| 使い方 | 開く場所 |
| --- | --- |
| ブラウザ版 | [TRPG Canvas Web](https://migawari558.github.io/TRPG_Canvas/) |
| Windows・Mac版 | [GitHub Releases](https://github.com/migawari558/TRPG_Canvas/releases) |
| ソースから起動 | 下記の「開発」を参照 |

デスクトップ版は端末上のファイルへ保存します。ブラウザ版はブラウザ内へ保存し、Google Drive同期を追加できます。

## 基本の執筆フロー

1. **フローチャートで流れを作る**
   シーンとグループを配置し、カード間を線でつなぎます。
2. **シーンから本文を作る**
   カードの「本文を書く」を押すと、対応する見出しと執筆欄が作成されます。
3. **目次で構成を整える**
   左側の目次から本文へ移動し、同じ階層の見出しを上下に並べ替えます。
4. **用途に合わせて書き出す**
   HTML、PDF、Word、Markdownから選びます。

すでに本文がある場合は、「既存の本文から」で章を上位グループ、H1をグループ、H2をシーンとしてフローを生成できます。

## 執筆機能

### ライブMarkdown

入力した記法をその場で見た目へ変換します。本文と執筆メモの両方で利用できます。

| 入力・操作 | 結果 |
| --- | --- |
| `#! ` | 章（H1より上、中央揃え） |
| `# ` ～ `###### ` | H1～H6見出し |
| `> ` | 引用・共有情報 |
| `- ` | 箇条書き |
| `[] ` / `[x] ` | 未完了／完了チェック項目 |
| `!!! ` | GMメモを開始 |
| `::話者名 ` | セリフを開始 |
| `**文字**` | 太字 |
| `*文字*` | 斜体 |
| `Ctrl+U` | 下線 |
| `Ctrl+F` / `Ctrl+H` | 検索／置換 |
| `Ctrl+Shift+D` | 空のセリフを開始 |
| `Ctrl+Enter` | GMメモ・セリフの外へ移動 |
| `Ctrl+S` | すぐに保存 |

通常のEnterとShift+Enterは、見た目の行間が揃うように表示します。空の段落もHTML・PDFで保持します。

### GMメモ

角丸と網掛けのブロックとして表示します。Markdownでは次の形式で保存します。

```markdown
:::gm
ここにGM向けのメモを書く。**太字**やリストも利用できます。
:::
```

GMメモはHTML・PDF・Wordにも含まれます。プレイヤー向けに自動で除外する機能はありません。

### セリフ

話者名と本文を横に並べます。NPC登録は不要で、話者名をブロックごとに入力できます。

```markdown
:::dialogue コレット
ダーリン、こちらの方々を見て。
:::
```

PDFでページや段をまたぐ場合は、続きにも話者名を表示します。

### 画像とチェックリスト

- 画像はツールバー、貼り付け、ドラッグ＆ドロップで挿入できます。
- PNG・JPEG・GIF・WebPに対応し、25%・50%・75%・100%へ変更できます。
- 画像データと代替文字は文字数に含めません。
- チェック項目はクリックで切り替え、Tab／Shift+Tabで階層を変更できます。

### 執筆メモ

本文とは別のメモ欄です。幅を変更でき、本文編集中とフローチャート編集中の両方で参照できます。Markdownをライブ表示しますが、書き出しには含めません。

## フローチャートと目次

- カードをドラッグして配置し、下の点から次のカードの上の点へ接続します。
- シーンをグループ枠へドロップすると、そのグループへ所属します。
- Ctrl／Commandクリックまたは背景ドラッグで複数選択できます。
- 複数シーンを同じグループへまとめて移動・削除できます。フローから削除しても本文は残ります。
- カード上でシーン名と本文に含めない短いメモを編集できます。
- 「対応する目次」を設定したカードをクリックすると、本文の該当見出しへ移動します。
- 目次の「すべて閉じる」「すべて開く」は、スクロールしても上部に残ります。

## 表示とテーマ

- 本文は12～28px、メニュー・目次は90～125%で調整できます。
- 端末にインストールされたフォントを選択できます。
- 詳細設定では本文、見出し、章、セリフ話者へ別のフォントを指定できます。
- フォレスト、Tahoe ライト／ダーク、羊皮紙、ミッドナイト、モノクロを収録しています。
- 背景、アクセント、見出し色を選ぶと、補助色を自動生成して自作テーマとして保存できます。

## 書き出し

| 形式 | 主な内容 |
| --- | --- |
| HTML | 階層目次、本文リンク、フロー、引用・コードのコピーボタンを含む単体ファイル |
| PDF | A4・A5・B5・レター、7～28px、1段／2段組み、テーマとフォントを指定 |
| Word | 編集可能なDOCX。PDFと同じ用紙・段組み・文字・テーマ設定を使用 |
| Markdown | 本文だけを持ち出すテキスト形式 |

PDFとWordではタイトルとフローチャートを全幅で配置します。PDFでは章・H1の改段、段頭の空行、GMメモや共有情報の分割を印刷向けに調整します。Wordの目次はWordで開いた際に更新されます。

## 保存と同期

### デスクトップ版

シナリオごとに`<ID>.trpg.json`を保存します。既定の保存先はドキュメント内の`TRPG Canvas`です。

Google Drive for desktopやDropboxの同期フォルダを「保存・同期」から選べば、各サービスのフォルダ同期をそのまま利用できます。同じシナリオを複数端末で同時編集した場合、検知できた変更は「競合コピー」として保護します。

### ブラウザ版

シナリオは常に先にブラウザへ保存します。「保存・同期」からGoogle Driveへ接続すると、約5秒の待ち時間を置いて自動同期します。

- `drive.appdata`スコープだけを使用します。
- 通常のマイドライブ内のファイルは読みません。
- シナリオ単位で新しい更新を残し、削除も同期します。
- サーバーや秘密鍵は不要です。
- 認証期限が切れた場合は、利用者が再接続します。

公開者向けのOAuth設定は[ブラウザ版の公開とGoogle Drive同期](docs/WEB-DEPLOYMENT.md)を参照してください。

## シナリオの管理

左上のロゴまたは「マイシナリオ」からダッシュボードを開きます。検索、並べ替え、新規作成、Markdown読み込み、削除ができます。

デスクトップ版の削除はOSのゴミ箱へ移動します。ブラウザ版は確認後にブラウザとGoogle Driveの同期データから削除します。

## 開発

Node.jsを用意して実行します。

```powershell
npm install
npm run dev       # Electron版を開発起動
npm run dev:web   # ブラウザ版を開発起動
npm run build     # 本番ビルド
npm start         # ビルド済みElectron版を起動
```

Google Driveをローカル確認する場合は、`.env.example`を`.env.local`へコピーしてOAuthクライアントIDを設定します。

### 関連するテスト

```powershell
npm run test:drive          # Driveの統合・削除・認証・アップロード
npm run test:docx           # Wordの用紙・段組み・文字・フロー
npm run test:pdf-page-sizes # PDFの用紙サイズ
npm run test:workflow       # フロー、空行、テーマ、HTML目次
npm run test:writer         # GMメモ、セリフ、執筆メモ
npm run test:images         # 画像挿入、サイズ、保存、書き出し
npm run test:tasks          # チェックリスト
```

全テストは`npm test`、配布用Windowsビルドは`npm run dist`で実行できます。テスト出力は`.test-output/`へ保存します。

## 現在の制限

- Google Driveのブラウザ同期には、公開者によるOAuthクライアントIDの設定が必要です。
- ブラウザだけの認証では、利用者が不在のまま期限切れトークンを更新できません。
- 同じシナリオのリアルタイム共同編集には対応していません。
- 表、脚注、任意HTML、外部URL画像の完全なMarkdown往復変換には対応していません。
- 選択したフォントが別端末にない場合は、標準フォントへ切り替わります。
- 配布用実行ファイルにはコード署名が付いていない場合があります。
