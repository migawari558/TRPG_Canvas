# TRPG Canvas

TRPGシナリオをローカルで執筆するデスクトップアプリです。React / Tiptap / React Flow / Electronで構築しています。

配布版は[GitHub Releases](https://github.com/migawari558/TRPG_Canvas/releases)に掲載します。Windows用exe、Apple Silicon Mac用dmg、Intel Mac用dmgを用意する構成です。Mac版はGitHub Actionsでビルド・検証します。公開前の版はReleasesの下書きとなります。

配布者向けの設定と署名の手順は[配布ガイド](docs/DISTRIBUTION.md)を参照してください。

## 起動

`release/TRPG Canvas 0.12.0.exe` がある場合は、ダブルクリックで起動できます（インストール不要）。

ソースコードから起動する場合はNode.jsをインストールした環境で実行します。

```powershell
npm install
npm run build
npm start
```

開発時は `npm run dev`、ブラウザでのプレビューのみなら `npm run dev:web` を使います。ブラウザ版はlocalStorageに保存します。フォルダの選択と直接のPDF出力はデスクトップ版の機能です。

## フローから書き始める

1. 「フローチャート」でシーン・分岐・結末を追加し、点どうしをつないで流れを組み立てます。フロー編集中は目次を隠し、作業場所を広く使えます。
2. 「グループ」で自由な枠を作成します。グループを選択してシーンを追加するか、既存のシーンをグループ枠の中へドラッグ＆ドロップすると、そのグループに所属します。入れ子の枠へドロップした場合は最も内側のグループに入ります。鉛筆ボタン →「所属グループ」からも変更できます。選択した枠の角でサイズを変えられます。
3. シーンの「本文を書く」で、シーン名の見出しと空の執筆欄を本文末尾に作り、その場で入力を始められます。既存の本文を使いたい場合は、鉛筆 →「既存の本文と紐づける」を使います。
4. 作成後は「本文を開く」で同じ箇所に戻ります。本文を重複作成しません。フローの名前と本文の見出し名は別々に編集できます。

グループは構想を整理するための枠です。所属変更で本文の順序・見出し階層は変わりません。グループ枠を削除しても内側のシーンや本文は残ります。従来の目次からのグループ化は「既存の本文から」に移動しました。

フローはCtrl＋クリック（MacはCommand）または背景のドラッグで複数選択し、「選択を削除」またはDeleteでまとめて削除できます。本文は削除されません。グループ枠だけを選んで削除すると、未選択の子シーンは外側に残ります。画面の移動は右ドラッグです。

目次には「すべて閉じる」「すべて開く」を追加しました。HTML冒頭の目次には章・H1・H2だけを表示し、H3以下の本文とリンク先は残します。テーマごとに章・主見出し・小見出しの色を分けています。

空の段落はHTML/PDFで空行として保持します。Markdownには `<!-- trpg-blank -->` という印を保存し、読み込み時に空行へ戻します。過去のシナリオも、保存済みの本文データに空段落が残っていれば、開いた際に反映されます。

## シナリオの削除

左上のロゴ（または「マイシナリオ」）からダッシュボードを開き、カード右上のゴミ箱ボタンを押します。シナリオ名を確認し、「ゴミ箱へ移す」で本文・フローを含むファイルを削除できます。デスクトップ版はWindowsのゴミ箱へ移し、失敗した場合に完全削除へ切り替えることはありません。同期フォルダの削除は他の端末にも同期されます。ブラウザ版は確認後にデータを完全削除します。確認後にファイルが変更された場合は削除を中止します。

## できること

- **画像挿入**：ツールバーの「画像を挿入」、画像の貼り付け、ファイルのドラッグで追加できます。PNG・JPEG・GIF・WebPに対応し、1枚5MB・2400万画素まで。画像はシナリオに埋め込むので、同期時に別ファイルを管理する必要はありません。HTML/PDFとMarkdownにも埋め込みます。外部URL・相対パスの画像は取り込まず、画像ファイルを挿入してください。容量上限に近い場合は追加前に通知します。
- **チェックリスト**：ツールバーの「チェックリスト」、または行頭の `[] `／`[x] ` で作成できます。従来の `- [ ] `／`- [x] ` も使えます。保存するMarkdownは `- [ ] `／`- [x] ` に統一します。クリックで状態を切り替え、Enterで次の項目、Tab／Shift+Tabで階層を変更します。GMメモ内でも使用でき、MarkdownとHTML/PDFにチェック状態を反映します。書き出したHTMLでのチェック操作は元のシナリオに保存されません。
- **斜体と改行**：日本語フォントでも斜体を表示できるようにしています。通常のEnterは段落、Shift+Enterは段落内改行のまま、段落の上下余白をなくして両者の行間を揃えています。見出しやメモ枠の余白は維持します。

- **表示設定と自作テーマ**：右上の「表示設定」で本文の文字サイズ（12〜28px）とメニュー・目次の文字サイズ（90〜125%）を個別調整。フォレスト・羊皮紙・ミッドナイト・モノクロの4テーマを選択できます。「このテーマをもとに作る」で土台を選び、背景・アクセント・見出し文字の3色だけ調整して、見本を見ながら保存できます。本文色やメモ枠などの補助色は自動生成し、見出しとアクセントの明暗も読みやすさに合わせて補正します。保存したテーマは後から編集・削除でき、HTML/PDFの書き出しテーマにも選べます。自作テーマと表示設定は端末ごとに保存します。
- **書き出しプレビュー**：HTML/PDFのテーマと文字サイズ（7〜28px）を画面とは別に指定し、右側で仕上がりを確認。「画面と同じ設定」で表示設定をコピーできます。PDFはA4・A5・B5（JIS）・レターの用紙サイズと1段／2段組みを選べます。デスクトップ版のPDFプレビューは、選んだサイズで実際に生成したPDFをページごとに表示します。ブラウザ版では印刷用HTMLの参考表示になります。最後に選んだ書き出しのテーマ・文字サイズ・用紙サイズ・段組みを保存します。HTMLプレビュー内のコピーボタンは見た目のみで、書き出したファイルで利用できます。
- **シナリオダッシュボード**：左上のロゴから、保存先のシナリオ一覧を取得して表示。タイトル・説明の検索、更新順／タイトル順の並び替え、新規作成・読み込みができます。サイドバーを閉じたときは、上部の「マイシナリオ」からも戻れます。一覧への移動前には編集中の内容を保存します。
- **ライブMarkdown編集**：記号のあとにスペースを入力すると、その場で見出し・引用・リストに変換。太字、斜体、打ち消し、コードブロック、区切り線にも対応。ツールバーでも操作できます。
- **GMメモ**：ツールバーの付箋ボタンで、角丸・網掛けのメモブロックを挿入。通常の段落を選んで押すとその段落をメモにでき、メモ内でもう一度押すと本文を残して装飾を解除します。見出しの位置では、見出し直後に空のメモを追加します。`Ctrl+Enter` でメモの外に通常の段落を作れます。HTML/PDFにも網掛けを反映します。
- **目次の並べ替え**：目次にマウスを重ねると表示される上下の矢印で、見出しと配下の本文・小見出しをまとめて移動。同じ親の同じレベルの見出し間で移動します。Ctrl+Zで戻せます。
- **フローチャート**：シーン・分岐・結末を追加してドラッグで配置。下の点から次のシーンの上の点へ接続。シーンの鉛筆ボタンや線のクリックから、名前・種類・条件ラベルの編集や削除ができます。
- **本文とフローの対応**：シーンの鉛筆ボタンから「対応する目次」を選択。リンク済みのシーンをクリックすると、シナリオ編集に切り替わって対応する見出しへ移動します。見出しの改名や並べ替えでもリンクは維持されます。削除した見出しへのリンクは警告表示になり、再設定できます。
- **階層グループ**：「既存の本文から」→「H1をグループ・H2をシーンに」で生成します。章は上位グループ、H1はグループ、H2はシーンとなり、H3以下からは新しいノードを作りません。子がないH1もグループになります。既存のシーンと接続は保持します。
- **左側の階層目次**：子見出しの折りたたみと、フローに紐づいた見出しのリンク表示。本文は17px、メニュー・目次も読みやすいサイズに拡大しています。
- **HTML出力**：目次リンク、任意のフローチャート、引用・コードのコピーボタンを含む単体HTML。外部サーバーやCDNなしで表示できます。ブラウザがコピーを拒否した場合は本文を選択するので手動でコピーできます。
- **PDF出力**：A4、日本語、任意のフローチャート。「書き出す」→「PDF」→「本文の段組み」で1段組み／2段組みを選べます。プレビューにも反映し、選択は次回も保持します。タイトルとフローは全幅、2段組みの本文は左段→右段→次ページの順に流れます。章・H1は最初の1つを除いて改段します（1段組みは改ページ）。GMメモ・共有情報は可能な限り枠ごと同じ段に保ち、一段に収まらない長さの場合は段・ページをまたぎます。共有用HTMLのボタンは印刷されません。
- **Markdown読み込み・書き出し**：本文を `.md` で持ち出せます。
- **自動保存**：変更後650msで保存。Ctrl+Sでも保存。ウィンドウを閉じる際も保存完了を待ちます。保存失敗時は閉じずにエラーを表示します。

最初の起動時には、操作を試せるオリジナルのサンプルシナリオが用意されます。以前のシナリオも読み込めます。見出し用のIDは初めて開いた際に追加されます。

### フローと目次をつなぐ手順

1. 本文に `#`（グループ）、`##`（シーン）で見出しを作ります。
2. フローチャートの既存シーンを使う場合は、鉛筆 →「対応する目次」で紐づけます。
3. 「既存の本文から」→「H1をグループ・H2をシーンに」で、足りないグループとシーンを作成します。
4. シーンをクリックすると本文へ移動します。本文の階層を変更した場合は、同じ操作で配置を更新できます。

「グループを解除」は位置と接続を保って全シーンを独立させます。グループ枠だけを削除した場合も、子シーンと本文は残ります。HTML出力にもグループ構造と本文へのリンクが含まれます。

### GMメモのMarkdown記法

GMメモは次の独自記法でMarkdownに保存され、再読み込み時に角丸・網掛けに戻ります。

```markdown
:::gm
ここにGM向けのメモを書く。**太字**や箇条書きも使えます。
:::
```

GMメモもHTML/PDFの書き出しに含まれます。プレイヤー向けに自動非公開にはなりません。

## Google Drive / Dropboxでの同期

1. 利用するすべてのPCにGoogle DriveまたはDropboxのデスクトップアプリを設定します。
2. 同期対象のフォルダを作り、オフラインでも利用できる状態にします。
3. TRPG Canvas左下の「保存・同期」でそのフォルダを選びます。
4. 別端末でも同じ同期フォルダを選びます。サービス側で同期が完了した後、ライブラリ右上の再読込ボタンで取り込みます。

クラウドAPIへの直接接続ではなく、各サービスのフォルダ同期を利用します。サービスの同期状態や完了はアプリからは判定しません。「保存済み」はローカルファイルへの保存完了を表します。

シナリオは `<ID>.trpg.json` の1ファイルに本文・編集用構造・フローチャートをまとめて保存します。既定の保存先はWindowsのドキュメント内の `TRPG Canvas` です。空の保存先へ切り替えると現在のシナリオをコピーします。すでにシナリオがある保存先を選ぶと、そのフォルダのシナリオを開きます。元の保存先は変更しません。

**同じシナリオの同時編集は避けてください。** 保存時に前回読込時と異なる内容を検知した場合、元ファイルを上書きせず「競合コピー」を作ります。このチェックはクラウドサービス全体の排他制御ではありません。チェック直後の変更や、サービス自身が生成した競合ファイルは手動での確認が必要です。定期的なフォルダのバックアップを推奨します。

## 現在の範囲

- デスクトップ配布はWindows向けです。スマートフォンや共同編集には対応していません。
- 対応するMarkdown要素は上記の基本記法です。表、外部URL／相対パスの画像、任意HTML、脚注、独自拡張の完全な往復変換には対応しません。
- `.md` 出力は本文のみです。フローも引き継ぐ場合は `.trpg.json` ファイルをコピーしてください。
- シーン名と本文の見出し名は別々に編集できます。リンク先の見出し名はシーン下部に表示されます。階層の再配置は「目次でグループ化」で明示的に実行します。
- HTML/PDFにはキーパー用メモも含まれます。プレイヤー向けに自動的に除外する機能はありません。
- 配布用実行ファイルにコード署名は付いていません。

## 章・下線・検索と置換

章はH1より上の階層です。ツールバーの「章（中央揃え・H1の上位）」、または行頭の `#! ` で追加します。Markdownでは `#! 第一章` のように保存されます。目次では章の配下にH1以下が入り、章全体を並べ替えたり、フローと対応付けたりできます。編集画面・HTML・PDFで中央揃えになります。書き出し時のH1〜H6は上の余白を下より広くして、見出しと本文をまとめています。

下線は文字を選択してツールバーの「下線」または **Ctrl+U** で切り替えます。HTML/PDFにも反映され、Markdownでは `<u>文字</u>` として保存します。読み込みでは属性のない下線タグのペアに対応します。

本文の検索・置換は虫眼鏡ボタンまたは **Ctrl+F / Ctrl+H** で開きます。現在のシナリオの本文・見出し・GMメモ・リスト・コードを検索し、該当箇所を強調表示します。Enter／Shift+Enterで次／前の結果、Escで閉じます。「1件置換」「すべて置換」と大文字・小文字の区別に対応し、置換後の文字を空欄にすると削除できます。一括置換はCtrl+Zでまとめて戻せます。検索は文字列の一致で、改行をまたぐ検索や正規表現、シナリオ名・フロー内だけの文字は対象外です。

npm run test:appearance # 文字サイズ・テーマの保存、HTMLプレビュー、PDFページ表示と書き出し
npm run test:typography # 日本語斜体と改行幅

npm run test:tasks # チェック状態・入れ子・Markdown往復変換
npm run test:search # 下線・検索・置換・取り消し・Markdown往復変換
npm run test:chapters # 章・並べ替え・保存・書き出し余白

スモークテストは `.test-output/` に隔離したブラウザデータ・画面画像・出力サンプルを作成します。コピーボタンの検証時は短時間ウィンドウを表示し、クリップボードにサンプル文章をコピーします。

主な実装は `src/App.jsx`（画面・自動保存）、`src/Editor.jsx`（本文）、`src/Flow.jsx`（フロー）、`src/model.mjs`（目次移動）、`src/export.mjs`（HTML）、`electron/storage.cjs`（ファイル・競合検出）、`electron/main.cjs`（デスクトップ連携・PDF）です。

使用したAPIの公式資料：[Tiptap React](https://tiptap.dev/docs/editor/getting-started/install/react)、[Electron printToPDF](https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions)。

保存先のドライブが未接続などで利用できない場合、起動時に保存先を選び直せます。既存のシナリオは移動・削除しません。同期ドライブを使う場合は接続を確認して元のフォルダを選択してください。

## 執筆画面とPDF（0.12）

左サイドバーに目次を移し、シナリオ一覧はロゴ・「シナリオ一覧へ」から開きます。右側の「執筆メモ」はシナリオ別に自動保存され、HTML/PDF/Markdown書き出しには含まれません。「執筆メモ」ボタンで開閉できます。

GMメモは行頭に `!!!` とスペースで開始し、Ctrl+Enterで外へ出ます。Markdown保存は `:::gm` と `:::` で囲む形式です。従来の `> [!GM]` も読み込めます。ツールバーボタンにマウスを置くと記法が表示されます。

PDFでは連続する章・H1を同じ段に保ちます。空の段落は段頭で省き、途中の空行・斜体後の改行は保持します。一段より長いGMメモ・共有情報は開始位置を次段に送らず分割し、ページ余白もテーマの背景色で塗ります。HTML/PDFは保存された編集データから直接描画します。
