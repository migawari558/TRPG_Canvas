# TRPG Canvas

TRPGシナリオをローカルで執筆するWindowsデスクトップアプリです。React / Tiptap / React Flow / Electronで構築しています。

## 起動

`release/TRPG Canvas 0.1.0.exe` がある場合は、ダブルクリックで起動できます（インストール不要）。

ソースコードから起動する場合はNode.jsをインストールした環境で実行します。

```powershell
npm install
npm run build
npm start
```

開発時は `npm run dev`、ブラウザでのプレビューのみなら `npm run dev:web` を使います。ブラウザ版はlocalStorageに保存します。フォルダの選択と直接のPDF出力はデスクトップ版の機能です。

## できること

- **ライブMarkdown編集**：記号のあとにスペースを入力すると、その場で見出し・引用・リストに変換。太字、斜体、打ち消し、コードブロック、区切り線にも対応。ツールバーでも操作できます。
- **目次の並べ替え**：目次にマウスを重ねると表示される上下の矢印で、見出しと配下の本文・小見出しをまとめて移動。同じ親の同じレベルの見出し間で移動します。Ctrl+Zで戻せます。
- **フローチャート**：シーン・分岐・結末を追加してドラッグで配置。下の点から次のシーンの上の点へ接続。シーンや線をクリックすると名前・種類・条件ラベルの編集や削除ができます。
- **HTML出力**：目次リンク、任意のフローチャート、引用・コードのコピーボタンを含む単体HTML。外部サーバーやCDNなしで表示できます。ブラウザがコピーを拒否した場合は本文を選択するので手動でコピーできます。
- **PDF出力**：A4、日本語、任意のフローチャート。共有用HTMLのボタンは印刷されません。
- **Markdown読み込み・書き出し**：本文を `.md` で持ち出せます。
- **自動保存**：変更後650msで保存。Ctrl+Sでも保存。ウィンドウを閉じる際も保存完了を待ちます。保存失敗時は閉じずにエラーを表示します。

最初の起動時には、操作を試せるオリジナルのサンプルシナリオが用意されます。

## Google Drive / Dropboxでの同期

1. 利用するすべてのPCにGoogle DriveまたはDropboxのデスクトップアプリを設定します。
2. 同期対象のフォルダを作り、オフラインでも利用できる状態にします。
3. TRPG Canvas左下の「保存・同期」でそのフォルダを選びます。
4. 別端末でも同じ同期フォルダを選びます。サービス側で同期が完了した後、ライブラリ右上の再読込ボタンで取り込みます。

クラウドAPIへの直接接続ではなく、各サービスのフォルダ同期を利用します。サービスの同期状態や完了はアプリからは判定しません。「保存済み」はローカルファイルへの保存完了を表します。

シナリオは `<ID>.trpg.json` の1ファイルに本文・編集用構造・フローチャートをまとめて保存します。既定の保存先はWindowsのドキュメント内の `TRPG Canvas` です。空の保存先へ切り替えると現在のシナリオをコピーします。すでにシナリオがある保存先を選ぶと、そのフォルダのシナリオを開きます。元の保存先は変更しません。

**同じシナリオの同時編集は避けてください。** 保存時に前回読込時と異なる内容を検知した場合、元ファイルを上書きせず「競合コピー」を作ります。このチェックはクラウドサービス全体の排他制御ではありません。チェック直後の変更や、サービス自身が生成した競合ファイルは手動での確認が必要です。定期的なフォルダのバックアップを推奨します。

## 現在の範囲

- デスクトップ配布はWindows向けです。スマートフォンや共同編集には対応していません。
- 対応するMarkdown要素は上記の基本記法です。表、画像、任意HTML、脚注、独自拡張の完全な往復変換には対応しません。
- `.md` 出力は本文のみです。フローも引き継ぐ場合は `.trpg.json` ファイルをコピーしてください。
- フローは本文と独立して編集します。見出しとの自動リンクや自動配置はありません。
- HTML/PDFにはキーパー用メモも含まれます。プレイヤー向けに自動的に除外する機能はありません。
- 配布用実行ファイルにコード署名は付いていません。

## 開発・検証

```powershell
npm test            # 見出し移動、階層境界、競合保存、HTMLエスケープ
npm run build      # 本番ビルド
npm run test:smoke # 実際のElectron画面で編集・保存・フロー・HTMLコピー・PDF生成
npm run test:desktop # デスクトップ用ファイル保存・書き出し・保存先設定
npm run dist       # Windowsポータブル版作成
```

スモークテストは `.test-output/` に隔離したブラウザデータ・画面画像・出力サンプルを作成します。コピーボタンの検証時は短時間ウィンドウを表示し、クリップボードにサンプル文章をコピーします。

主な実装は `src/App.jsx`（画面・自動保存）、`src/Editor.jsx`（本文）、`src/Flow.jsx`（フロー）、`src/model.mjs`（目次移動）、`src/export.mjs`（HTML）、`electron/storage.cjs`（ファイル・競合検出）、`electron/main.cjs`（デスクトップ連携・PDF）です。

使用したAPIの公式資料：[Tiptap React](https://tiptap.dev/docs/editor/getting-started/install/react)、[Electron printToPDF](https://www.electronjs.org/docs/latest/api/web-contents#contentsprinttopdfoptions)。
